# File Organizer

A simple Python desktop application that automatically organizes files into different folders based on their file types.

## Features

- Select a folder using the Browse button
- Automatically identify file types
- Create folders based on file categories
- Move files into the correct folders
- Prevent duplicate file names from being overwritten
- Display the number of files organized
- Simple graphical user interface

## File Categories

The application organizes files into:

- Images
- Documents
- Videos
- Audio
- Archives
- Code
- Others

## Technologies Used

- Python
- Tkinter
- OS module
- Shutil module
